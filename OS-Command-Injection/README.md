# OS Command Injection

This directory contains my hands-on walkthroughs for the **OS Command Injection** labs from the PortSwigger Web Security Academy.

## About

OS Command Injection occurs when an application passes unsanitized user input to an operating system command, allowing an attacker to execute arbitrary commands on the underlying server.

| ⬜ | OS command injection, simple case |
| ⬜ | Blind OS command injection with time delays |
